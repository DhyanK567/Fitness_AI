Zero Trust Execution Flow

Every request flowing through the NestJS Gateway undergoes strict tenant resolution, cryptographic JWT claim validation, and database session scoping before reaching business logic.

Step 01 · Client Inbound
Tenant Context Guard
Extracts x-tenant-id header or subdomain; validates tenant presence and UUID structure.
Step 02 · Gateway IAM
Staff Access Guard
Verifies HS256 JWT signature; rejects cross-tenant tokens (token.tenant !== req.tenantId).
Step 03 · RBAC Matrix
Policy Enforcement
Validates required permissions (e.g. staff:write) against user role with default-deny.
Step 04 · Data Boundary
PostgreSQL RLS Session
Executes SET LOCAL platform.current_tenant ensuring row-level multi-tenant isolation.
Step 05 · ERP Integration
Frappe Row Lock
Executes transactional booking with SELECT ... FOR UPDATE preventing race conditions.

const authHeader = request.headers['authorization'];
if (!authHeader || !authHeader.startsWith('Bearer ')) {
  throw new UnauthorizedException('Missing bearer token');
}

const token = authHeader.substring(7);
const claims = verifyAccessToken(token);

// Strict Cross-Tenant Matching Barrier
if (claims.tenant !== request.tenantId) {
  throw new ForbiddenException('Tenant context mismatch between token claims and request');
}

const requiredPermission = this.reflector.get<string>('permission', context.getHandler());
if (requiredPermission && !hasPermission(claims.role, requiredPermission)) {
  throw new ForbiddenException(`Forbidden: role ${claims.role} lacks ${requiredPermission}`);
}

Concurrency-Safe Class Booking & Waitlist Engine

erpnext-custom-app/wellness_studio/api/booking.py

To prevent race conditions during high-demand class booking rushes, Yashwanth engineered row-level locking via PostgreSQL/MariaDB FOR UPDATE.

booking.py · Atomic Seat Reservation 
def _session(session: str, tenant: str):
    row = frappe.db.sql(
        """
        SELECT name, capacity, confirmed_count, waitlist_count, status
        FROM `tabWS Class Session`
        WHERE name = %s AND tenant = %s
        FOR UPDATE
        """,
        (session, tenant),
        as_dict=True,
    )
    if not row:
        frappe.throw(_("Class session not found"), frappe.DoesNotExistError)
    return row[0]

@frappe.whitelist()
def book(member: str, session: str, tenant: str):
    tenant = _tenant(tenant)
    # Check duplicate booking
    if frappe.db.exists("WS Booking", {"tenant": tenant, "member": member, "session": session, "status": ["in", ["Confirmed", "Waitlisted"]]}):
        frappe.throw(_("Member already has a booking for this session"), frappe.DuplicateEntryError)

    session_row = _session(session, tenant)
    status = "Confirmed" if (session_row.confirmed_count or 0) < (session_row.capacity or 0) else "Waitlisted"
    booking = frappe.get_doc({
        "doctype": "WS Booking", "tenant": tenant, "member": member,
        "session": session, "status": status,
    })
    booking.insert(ignore_permissions=True)
    field = "confirmed_count" if status == "Confirmed" else "waitlist_count"
    frappe.db.set_value("WS Class Session", session, field, (getattr(session_row, field) or 0) + 1, update_modified=False)
    return {"booking_id": booking.name, "status": status}

Transactional Audit & Outbox Engine

To prevent distributed transaction failures where database state changes but asynchronous events or audit trails are lost, Syed implemented transactional dual-write:

audit-outbox.service.ts · Atomic Dual Write 
await this.prisma.$transaction(async (tx) => {
  // 1. Write Append-Only Audit Log
  await tx.auditLog.create({
    data: {
      tenantId: payload.tenantId,
      actorId: payload.actorId,
      action: payload.action,
      resource: payload.resource,
      resourceId: payload.resourceId,
      metadata: payload.metadata,
      occurredAt: new Date(),
    }
  });

  // 2. Write Outbox Event for Message Brokers
  await tx.outboxEvent.create({
    data: {
      tenantId: payload.tenantId,
      eventType: payload.eventType,
      payload: payload.outboxPayload,
      status: 'PENDING',
      createdAt: new Date(),
    }
  });
});
